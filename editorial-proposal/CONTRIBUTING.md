# Contributing / Mitmachen / Collaborare
**Community proposal, not official DSM policy.**

## Deutsch
Bitte eröffne ein Issue für Ideen, Zweisprachigkeit oder Barrierefreiheit. Für konkrete Änderungen nutze einen Fork und Pull Request. Nenne Zielgruppe und Lernziel. Nur synthetische und zur Veröffentlichung berechtigte Beispiele.

## Italiano
Apri un'Issue per discutere impaginazione, traduzioni, accessibilità e metadati. Per modifiche concrete, usa un fork e una Pull Request. Indica destinatari, motivazione pedagogica e possibile impatto sulle competenze valutate. Solo allegati sintetici e pubblicabili.

## English
Use Issues and Pull Requests. For assessments, distinguish visual changes from authorized learning accommodations.

## Review
1. Issue for ideas and rationale; synthetic example where helpful.
2. Pull Request with before/after, affected profiles, translation and accessibility impact.
3. Maintainer review for fidelity, licensing and privacy; specialist review when assessment semantics change.
4. No school approval is claimed; published releases require explicit approval from the authorized party.

Never submit real pupil names, grades, diagnoses, protected materials, unpublished exam papers, private correspondence, IDs, signatures or credentials.
