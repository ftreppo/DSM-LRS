# DSM-LRS
Offenes Projekt zur LRS-Unterstützung an der Deutschen Schule Mailand: adaptive Lernmaterialien, dokumentierte Regeln, Benutzerhilfen und portable Werkzeuge. Progetto aperto per il supporto LRS alla Scuola Germanica di Milano: materiali didattici adattivi, regole documentate, guide utente e strumenti portabili.
