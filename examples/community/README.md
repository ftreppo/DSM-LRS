```text
examples/community/
├── README.md
└── reviewed/
    ├── study/
    ├── homework/
```

- Nummer des Quell-Issues;

- synthetisches/anonymisiertes Ausgangsmaterial;

## Struttura

```text
examples/community/
├── README.md
└── reviewed/
    ├── study/
    ├── homework/
    └── assessment/
```

Ogni esempio revisionato dovrebbe includere:
- numero della Issue di origine;
- versione Adapter;
- modalità d'uso;
- materia;
- materiale sorgente sintetico/anonimizzato;
- output dell'Adapter;
- analisi del reviewer;
- classificazione;
- eventuale ID del candidato di miglioramento;
- stato del controllo privacy/diritti.

Non conservare qui dati personali o protetti.

# English

This area contains **reviewed, public-safe** examples contributed through the Community Adapter Lab.

Raw submissions remain GitHub Issues and are **not canonical examples**.

## Structure

```text
examples/community/
├── README.md
└── reviewed/
    ├── study/
    ├── homework/
    └── assessment/
```

Every reviewed example should include:
- source Issue number;
- Adapter version;
- use case;
- subject;
- synthetic/anonymized source material;
- Adapter output;
- reviewer analysis;
- classification;
- improvement candidate ID if applicable;
- privacy/rights review status.

Do not store personal or protected data here.
