# Reviewed community examples

Only curated examples that passed privacy/rights review belong here.

Recommended file naming:

`CAE-YYYY-NNN-short-description.md`

Recommended status block:

```yaml
community_example_id: CAE-YYYY-NNN
source_issue: 123
adapter_version: 0.1.0
use_case: STUDY|HOMEWORK|ASSESSMENT
classification:
  - GOOD_EXAMPLE
privacy_review: PASS
rights_review: PASS
adapter_change: NONE|CANDIDATE:<id>
```

Subfolders:
- `study/`
- `homework/`
- `assessment/`
