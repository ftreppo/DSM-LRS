# Private traceability boundary

The original v2.5.1 release package also contains machine-readable release/conformance JSON files with internal Google Drive identifiers.

Those files are **not copied verbatim to this public repository**.

Public migration rule:
- publish product semantics and non-sensitive release documentation;
- keep private storage identifiers in private migration/audit evidence;
- publish sanitized machine-readable metadata later only if internal locators are removed or replaced with public repository references.

The Adapter core files are migrated separately after content/read-back verification.
